حزمة سيرفر لعبة المعارك الجماعية

المحتويات:
- server.js: كود السيرفر.
- package.json: إعدادات المشروع واعتمادية WebSocket.

التشغيل محلياً:
1) ثبّت Node.js إصدار 18 أو أحدث.
2) فك ضغط الحزمة.
3) افتح الطرفية داخل المجلد وشغّل: npm install
4) شغّل السيرفر: npm start
5) افحص حالة السيرفر عبر المسار /health على المنفذ الذي يستخدمه السيرفر.

النشر على Render:
- ارفع محتويات هذا المجلد إلى مستودع Git.
- أنشئ Web Service جديداً من المستودع.
- Build Command: npm install
- Start Command: npm start
- لا تثبّت منفذاً ثابتاً؛ يستخدم السيرفر PORT الذي توفره بيئة الاستضافة.

ملاحظة مهمة:
هذه الحزمة تضم ملف السيرفر وإعدادات تشغيله فقط. يلزم اختبار مباراة فعلية بلاعبين للتأكد من توافق مزامنة البناء مع نسخة اللعبة المنشورة. لا تغيّر رابط WebSocket في اللعبة إلا إذا كان يشير إلى عنوان السيرفر المنشور الصحيح.
